"Smart Hybrid" va Multi-Tenant Arxitekturasi

1. Smart Hybrid: Internet Uzilganda Ham 100% Himoya

O'zbekistondagi hududiy ta'lim muassasalarida tashqi internet aloqasi yoki markaziy AI server bilan aloqa uzilib qolsa ham, litsey shlyuzidagi AdGuard Home / DNS Edge Agent mustaqil ishlaydi. Barcha dars jadvallari, domen taqiqlari va fishing filtrlari lokal keshdan 0 millisoniya kechikish bilan tekshiriladi. O'quvchilar dars vaqtida taqiqlangan saytlarga internet qayta ulanguncha ham kira olmaydi.

2. Multi-Tenant SaaS (Yuzlab Litseylar Uchun Yagona Ekotizim)

Respublikadagi har bir litsey o'zining unikal "Litsey ID" (masalan, UZ-TAS-AL01) orqali markaziy Supabase bulut bazasiga ulanadi. Row Level Security (RLS) orqali ma'lumotlar mutlaqo xavfsiz izolyatsiya qilingan. Bitta litsey ma'muri boshqa litseyning kompyuterlari yoki loglarini ko'ra olmaydi.

3. FastAPI + VirusTotal + Gemini Vision Uch Bosqichli Filtrlash

- 1-bosqich: Lokal DNS filtri (AdGuard) - dars vaqti soatlari va qora ro'yxat.
- 2-bosqich: VirusTotal API (72 ta antivirus dvigateli) - binar fayllarni xesh bo'yicha tahlili.
- 3-bosqich: Gemini Vision AI - chatlar orqali uzatilayotgan tasvirlarni vizual tahlil qilib, kiberbulling va nomaqbul materiallarni aniqlash.
